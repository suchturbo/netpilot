# Port link is down

A port with no link and admin state enabled means nothing electrical is reaching it: an unplugged or failed cable, a powered-off endpoint, or a dead port.

Check that the device on the other end is powered, reseat or swap the cable, and try a known-good port to separate a bad port from a bad cable.

# Port is administratively disabled

A port that was disabled on purpose shows admin state off. Confirm with the change log or the owner before enabling it again, because ports are often shut to isolate a misbehaving device.
